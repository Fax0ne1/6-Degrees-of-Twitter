# 6 Degrees of Twitter

Project description:
A way to simulate connections between users, finding out if one is 
elated to another by a series of hops. Uses sets, graphs, and BFS
algorithms.

The GitHub directory isn't the proper layout for the project to run.

## Files Used

Python: mutuals.py, all visuals files
Rust: graph.rs, rust_to_python.rs, main.rs, input.rs (1 function)
accounts.txt or accounts.db

### Prerequisites

Languages:
- Rust 1.90
- Python 3.11 or higher
